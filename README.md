# Avalon Judge · 阿瓦隆单机电子裁判

> 一部手机当裁判，现场全是玩家也能开局。
> 纯静态、零依赖、零构建、零后端；双击 `index.html` 就能玩。

一个为线下桌游设计的单机网页应用：从设置人数、分发身份、夜晚互认、组队投票、任务判定到刺杀复盘，全流程由手机托管。**特别针对「没有中立裁判」的场合**，把睁眼环节做成全自动语音／字幕裁判。

- **不需要联网**：所有逻辑、图片、语音都在本地文件里
- **不需要安装**：浏览器打开即用，微信内置浏览器也可
- **不需要服务器**：存档只存在当前设备的浏览器里，各设备之间不互通

---

## 快速开始

```bash
# 方式一：直接双击
打开 avalon/index.html        # file:// 可用，无需任何服务器

# 方式二：起个本地静态服务（可选）
cd avalon && python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080
```

部署到任意静态托管时，上传**整个 `avalon/` 目录**（含 `css/`、`js/`、`cards/`）。只传 `index.html` 会白屏或缺图。

> 项目使用经典 `<link>` / `<script src>`，刻意**不用 ES Module**：ESM 在 `file://` 下会被 CORS 拦截，双击就打不开了。

## 它解决什么问题

阿瓦隆的「夜晚环节」通常需要一位不参与游戏的裁判念口令、控制谁睁眼。人不够时游戏就卡住。

本项目的**语音裁判**把这段完全交给手机：

1. 设置页第 1 步顶部选择「语音裁判」
2. 依次传递手机，每人只看自己的身份牌
3. 递完牌进入准备页 → **先点「🔊 试听一句」**确认有声音
4. 把手机平放桌面中央，点「▶ 开始语音裁判」
5. 口令逐句自动播出，名单自动显示与收起，末步自动进入组队环节，全程无需任何人操作手机

准备页还提供「📜 只用字幕」（安静场合，大字口令自动翻页）和「改用人工裁判」。播放中可 ⏸ 暂停 / 🔁 重播本句 / ⏭ 跳过本句。

**红线**：语音只播公开的睁眼口令，**绝不播报玩家姓名**；名单仅靠屏幕自动显隐。

## 功能

| | |
|---|---|
| 人数 | 5–10 人，可自定义姓名（留空用默认名） |
| 身份 | 8 种角色，每人只看自己的牌；秘密名单只在内存中短暂显示，不写入存档 |
| 流程 | `SETUP → DEAL → EYES → TEAM_BUILD → TEAM_VOTE → QUEST → ASSASSINATE → GAME_OVER` |
| 投票 | 发车投票逐人记录、平票视为否决；连续 2 次否决后本次组队自动发车 |
| 任务 | 逐人提交成功／失败票，实时显示任务进度 |
| 语音 | 内置 8 句中文口令音频，微信与外部浏览器同一播放路径 |
| 视觉 | 8 张统一风格角色立绘、深金手抄本主题、单屏星宇首页与角色图鉴 |
| 存档 | `localStorage`，刷新／误关可恢复；中途退出主按钮变为「继续本局」 |

## 语音是怎么做的

早期版本调用浏览器的 `speechSynthesis`，但微信 WebView 和部分手机浏览器要么阉割了这个能力，要么没装中文语音包，表现为「点了没声音」。**当前版本已彻底换掉这条路**：

- 8 句口令用 `edge-tts`（`zh-CN-YunjianNeural`，`rate=-5%`）预录成 mp3，base64 内联在 `js/00-audio.js` 里，随页面一起加载
- 播放优先走 Web Audio `AudioBufferSourceNode`（在用户点击手势里解锁 iOS／微信输出），解码失败退回 `<audio data:uri>`，连续失败才转字幕托管，**绝不卡住对局**
- 不依赖浏览器朗读能力、系统中文语音包或任何外部服务

源文件在 `voice-source/01..08.mp3`（不在运行目录内，仅用于重建）。若改动了 `js/03-game.js` 里任何一句 `say` 的文案，**必须同步重建音频包**，否则该句会播放失败并回退到字幕。

```bash
pip install edge-tts
python -m edge_tts --voice zh-CN-YunjianNeural --rate=-5% \
  --text "口令原文" --write-media out.mp3
```

> **物理限制**：媒体音量为 0 或 iPhone 静音拨键未关闭时，任何方案都发不出声。所以准备页把「试听一句」放在明面上。

## 实现要点

- **状态与存档**：`LS_KEY = 'avalon_judge_state_v2'`，设置草稿 `avalon_setup_draft_v1`，裁判偏好 `avalon_judge_mode_v1`。角色字段做可逆混淆后入库；秘密名单、语音运行时状态只存在内存，刷新后回到「未展开」状态。所有 `localStorage` 读写都有安全封装，隐私模式下也不会抛错阻断流程。
- **微信缓存**：线上静态资源没有 `Cache-Control` / `ETag`，微信 WebView 会长期强缓存同名 JS。因此 `index.html` 给全部 CSS/JS 加了 `?v=15`，并在启动时检测 `window.APP_VERSION`，发现加载的是旧缓存就显示「刷新到新版」横幅。**每次重新部署都要递增 `?v=N`、同步 `js/05-boot.js` 的 `APP_VERSION` 与首屏脚注版本号，并使用带新版本号的地址**。
- **旧存档自愈**：早期版本出故障时会把「本局 = 人工裁判」写进存档。启动时会识别这种情况并自动改回全自动托管；人工睁眼页也留了「一键改回全自动托管」按钮，不用重开本局。
- **立绘显示**：原图 640×750，统一用 `aspect-ratio: 640/750` + `object-fit: contain` 完整显示，不做裁切。

## 已知限制

- **单机应用**：没有联机、没有账号、没有云数据。存档只在各自设备上，换手机不会同步。
- **声音依赖设备**：音量 0 / 静音拨键时无声，请先试听。
- **线上链接依赖托管平台**：项目本体不依赖任何线上服务，但如果你用的是 WorkBuddy 托管的分享链接，其存续取决于平台服务与账号状态，官方未承诺永久有效。链接失效不影响本地文件，双击 `avalon/index.html` 照常可玩。
- **未指定开源许可证**：见文末说明。
